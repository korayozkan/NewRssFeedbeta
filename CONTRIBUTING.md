# Contributing to NewRssFeed

Thank you for your interest in contributing to NewRssFeed! We appreciate your help in making social media reading cleaner and more organized.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub with:
- A clear description of the bug.
- Steps to reproduce.
- Screenshots or console logs if applicable.

### Suggesting Enhancements
Feature requests and UI/UX improvements are always welcome. Feel free to open an issue or submit a pull request.

### Pull Requests
1. Fork the repository (`https://github.com/korayozkan/NewRssFeedbeta`).
2. Create a new feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes (`git commit -m 'Add some amazing feature'`).
4. Push to the branch (`git push origin feature/amazing-feature`).
5. Open a Pull Request.

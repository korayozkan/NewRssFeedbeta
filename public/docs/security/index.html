Güvenlik

Güvenlik açığı bildirimi

NewRssFeed’de güvenlik sorunu fark ettiysen, ayrıntıları herkese açık olarak paylaşmadan önce bakım ekibine özel olarak ilet.

Nasıl bildirim gönderilir?

Açığın kısa açıklamasını, etkisini ve tekrar üretme adımlarını kiruhiofficial@proton.me adresine e-postayla gönder. Gerçek kullanıcı verilerini veya sana ait olmayan sırları bildirime ekleme.

Yanıt süreci

Projenin güvenlik politikası, bildirimin 48 saat içinde alındığının onaylanacağını belirtir. Çözüm süresi sorunun niteliğine ve bakım durumuna bağlıdır.

Güvenlik açığı ayrıntılarını düzeltme yapılmadan önce herkese açık issue, tartışma veya sosyal medya gönderilerinde yayımlama.

Genel hata ve ürün önerileri

Güvenlik riski taşımayan hata bildirimleri ve fikirler için GitHub Issues veya katkı rehberi kullanılabilir.
